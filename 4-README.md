# Planificador de Apps (borrador)

Herramienta sencilla para convertir una idea de app en un plan, unas instrucciones para la IA y un presupuesto.

- Funciona solo en el navegador (HTML, CSS y JavaScript sin frameworks). No usa IA ni servidor.
- Los datos se guardan solo en este navegador con el botón «Guardar»; no se sincronizan entre dispositivos.
- Las propuestas del recorrido son ideas de diseño con reglas fijas (ahora reservas y carta), no requisitos verificados.
- Los avisos de riesgo se detectan por palabras clave y pueden fallar.
- Versión de prueba: no usar con datos reales de clientes.
